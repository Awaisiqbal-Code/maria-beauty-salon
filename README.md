A luxury beauty salon website built with pure HTML, CSS & JavaScript — featuring glassmorphism design, rose gold aesthetics, and premium animations.

- 🎨 Luxury glassmorphism design (Rose Gold + Soft Pink)
- 📱 Fully responsive — Mobile First
- ⚡ Smooth scroll animations & reveal effects
- 🖼️ Pinterest-style masonry gallery with category filters
